# LBrain for VS Code

Thin helper. The memory engine is the PyPI package `lbrain`. This extension does not reimplement it.

**Add the MCP server:** Command Palette → `LBrain: Add MCP server`, or Extensions search `@mcp lbrain` once the Official MCP Registry listing is live.

Install the engine:

```
pip install "lbrain[local]" lbrain-coding-agents
```
